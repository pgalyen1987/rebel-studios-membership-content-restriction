# Membership & Content Restriction

Turn any WordPress site into a members area. Every page and post gets one of three settings — **public**, **logged-in users only**, or **members only** — and anyone who does not qualify reads your message where the content was.

**Install it from the WordPress Plugin Directory:**
→ https://wordpress.org/plugins/rebel-studios-membership-content-restriction/

A free, GPLv2 plugin by [Rebel Studios](https://rebelstudiossoftware.com).

## What it does

- **Three visibility levels** on every page and post, set from one box in the editor.
- **Front-end sign-up and login**, so visitors join without ever seeing wp-admin.
- A **member directory** shortcode that lists the people who have joined.
- **No member limit.**

It is three shortcodes (`rsmb_register`, `rsmb_login`, `rsmb_directory`) and one box in the post editor. None of those three is behind a paywall.
